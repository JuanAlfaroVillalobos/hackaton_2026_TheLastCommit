Cómo instalarla

  1. Toca Descargar para Android desde tu celular.
  2. Abre el archivo descargado (vecinos.apk) desde la notificación o la carpeta Descargas.
  3. Si Android lo pide, permite instalar apps de esta fuente para tu navegador.
  4. Toca Instalar y luego Abrir. Verás el tutorial de bienvenida.
